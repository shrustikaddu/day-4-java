# Java Calculator

## About the Project
This is a simple Calculator application developed using Java.
It performs basic arithmetic operations using a class and methods.

## Features
- Addition
- Subtraction
- Object creation
- Method implementation

## Technologies Used
- Java
- VS Code

## Code Structure
- Calculator class
- add() method
- subtract() method
- Main class

## Output
Addition: 30
Subtraction: 10

## How to Run

1. Compile the program:
   javac Main.java

2. Run the program:
   java Main

## Learning Outcomes
- Understanding Java classes and objects.
- Learning methods and return statements.
- Understanding object creation.
- Practising basic arithmetic operations.
